## 🌐 Portfolio Website

This repository contains my **personal portfolio website** built with modern web technologies.

### **Tech Stack**
- ⚛️ **React** + **TypeScript** - Component-based UI architecture
- 🎨 **GSAP** - High-performance animations and ScrollTrigger
- 🎮 **Three.js** - 3D graphics and WebGL rendering
- ⚡ **Vite** - Lightning-fast build tool
- 🎯 **React Three Fiber** - Declarative 3D scene management
- 📦 **React Three Rapier** - Physics engine integration

### **Features**
- ✨ Smooth scroll animations with GSAP ScrollTrigger
- 🎭 Interactive 3D character with physics simulation
- 📱 Fully responsive design (mobile + desktop)
- 🎨 Custom cursor interactions
- 🎯 Horizontal scroll project showcase
- 📊 Interactive tech stack visualization with physics
- 🚀 Optimized performance and lazy loading

### **Getting Started**

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
